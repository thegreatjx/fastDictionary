# fast词典 · 纸墨设计系统

> 桌面原生速度 × 考究阅读体验。本文是实现契约，颜色以 `theme.go` 的
> `newAppTheme` 与 `accentChoices` 为准。

## 1. 设计原则

1. **内容是主角。** 界面是纸，词条和译文是墨。卡片、工具条和设置页都不与正文抢视线。
2. **一个强调色。** 全局只有一处色相用于交互，其余都是中性纸面与墨阶。强调色可由用户选择，但不能同时出现第二种强调色。
3. **状态不占色相。** 成功、完成、已保存用图标、文字和位置表达，不用绿色填充。只有真正的失败和警告才允许出现陶红与赭石。
4. **层级靠字阶、留白和发丝线。** 不靠彩色块、渐变、发光和大阴影。
5. **原生优先。** 所有界面用 `github.com/egoist/mygo/ui` 的 Go API 绘制，禁止 WebView、HTML 和 CSS。

**禁止**给原文条、提示卡、写作卡加大面积浅蓝、浅绿或琥珀底色。微底只能是中性纸面。

## 3. 可选主题色

设置 → 通用 → 主题色。四个选项都是低饱和墨色，切换只影响焦点环、链接、选中态和主交互按钮，纸面与语义色不变。

| 名称 | Value | 浅色 | 深色 |
| --- | --- | --- | --- |
| 黛青（默认） | `slate` | `#34566F` | `#9DBBD1` |
| 靛蓝 | `indigo` | `#3D4E86` | `#A7B6E8` |
| 紫檀 | `plum` | `#5C3F5E` | `#C6A9C9` |
| 石墨 | `graphite` | `#3A3D42` | `#C2C6CC` |

规则：

- **不再跟随 Windows 系统强调色。** 系统色可能是荧光绿或高饱和蓝，会直接破坏纸面。
- 未配置或值未知时回落到 `slate`，旧配置不会出现零色。
- 选中态仍由 `AccentSoft` + `AccentRing` 表达，不使用第二种色相。

## 4. 语义色

| 语义 | 浅色 | 深色 | 使用范围 |
| --- | --- | --- | --- |
| Danger 陶红 | `#A34A3E` | `#D98B80` | 保存失败、翻译失败、删除确认；只染文字与图标 |
| Warning 赭石 | `#8A6A3A` | `#D2B078` | 快捷键冲突、模型不可用等真实警告 |
| Success | 无独立色相 | 无独立色相 | 用 `iconCheckSquare` + `TextMuted` 表达 |

**已保存不使用绿色。** 卡片底部把主按钮换成一行中性文字：

```
✓ 已保存
```

12px 图标 + 11px 文字，`TextMuted`，无底色、无描边、无绿色勾。

**保存成功不弹横幅。** 按钮变成「已保存」本身就是确认；再出现一条绿色通知等于把同一句话说两遍。只有保存失败才显示一行陶红原因。

**复制成功不弹横幅。** 复制图标在 3 秒内换成勾，提示文案变成「译文已复制」，随后恢复。

## 5. 字体

- UI 字体栈：`Segoe UI Variable Text, Segoe UI, Microsoft YaHei UI`
- 音标：`Segoe UI, Lucida Sans Unicode, Arial Unicode MS`
- 等宽：`Cascadia Mono, Consolas`
- 字阶：
  - Page Title `20px` / 600
  - Word Head `18px` / 700
  - Section `14px` / 600
  - Body / Control `13px` / 400–500
  - Helper `12px` / 400
  - Micro / Badge `11px` / 500–600
- 正文行高 1.5–1.6；长文最大阅读宽度 600 DIP。
- 字重最多 600（词头 700），不使用 800/900 制造层级。

## 6. 间距与圆角

- 间距模数：4 / 8 / 12 / 16 / 24 / 32 DIP。
- 圆角：
  - 徽章 `4px`
  - 控件 `6px`
  - 卡片 / 分组 `8px`
  - 窗口 `10px`
  - 悬浮胶囊为完整圆弧，高度 36 DIP
- 控件高度：紧凑 28 / 常规 32 / 搜索 34 DIP。
- 主布局不使用 5、10、14 这类散值；图标光学修正允许 1–2 DIP。

## 7. 组件契约

### 按钮

| 类型 | 静止 | 悬停 | 按下 |
| --- | --- | --- | --- |
| 主操作（保存） | 墨色 `#1A1C1E` / `#E8E9EB` | 深一档 | 再深一档 |
| 交互（强调） | `Accent` | `AccentHover` | `AccentPress` |
| 次要 | Surface + BorderCtrl | SurfaceHover + BorderHover | SurfacePress |
| Ghost 图标 | TextSec，无边 | SurfaceHover | SurfacePress |

保存按钮的前景色与图标同色，深色主题下反转为近白底 + 近黑字。

### 图标按钮

- 尺寸 28×28，图标 16 或 14。
- 静止 `TextSec`，悬停 `SurfaceHover`，按下 `SurfacePress`。
- 选中态用 `AccentSoft` 底 + `Selected(true)` 语义，补键盘焦点环。
- 每个纯图标按钮必须有 tooltip 和可访问名称，不允许只靠颜色表达状态。

### 分段控制器

- 轨道 `SurfaceSubtle` + `BorderSubtle`，选中滑块 `SurfaceElev` + 1px 发丝边。
- 选中文字 `Text` / 600，未选中 `TextSec` / 500。
- 只在「翻译 / 长难句 / 写作」和设置页三档排版中使用，不堆叠第二套 Tab。

### 徽章

- CEFR：中性 `SurfaceSubtle` 底，靠墨阶区分难度。
  - C：`Text`
  - B：`TextSec`
  - A：`TextMuted`
- 词性：中性描边胶囊，文字 `TextSec`。
- 不使用绿/蓝/紫三色难度徽章。

### 长难句标注

六个语法角色是唯一允许功能色的地方，因为颜色在这里承载句法信息。色板见 `grammarInkFor`：

- 主语 青 `#2F6F7A`
- 谓语 蓝 `#2A57C4`
- 宾语 梅 `#8A4B6B`
- 补语 紫 `#6F4AA8`
- 连接 橄榄 `#4C7A3F`
- 难点 陶土 `#B05A3C`

线型（实线/波浪/双线/点线）同时区分角色，不允许只靠颜色。卡面保持中性，不做彩色底。

### 写作卡

- 「改后版本」用中性 `TintSurface` 卡，不用浅绿整块。
- 删除用陶红 `#8A4A42`，新增用当前强调色；分类标签用中性描边。
- 保存状态与词卡一致：主按钮变中性「已保存」，不弹横幅。

### 悬浮条

- 底色中性纸面 `#FCFCFA` / `#1C1D1F`，发丝边 `#E2E2DD` / `#2E3136`。
- 图标墨色 `#4B5057` / `#B4B9C0`；唯一强调图标用 `Accent`。
- 悬停只加深墨色并加中性微底，不按按钮换色相。
- 提示气泡深底浅字 / 浅底深字，与悬浮条同族，不用系统 Inverse。

## 8. 动效

- 阅读面（弹窗、卡片、设置页）只做 120–160ms 的颜色与位置过渡。
- 不使用弹跳、发光、呼吸和自动播放动画。
- 拖动浮窗时避免整棵树重建；`applyTheme` 在色板未变化时直接返回。

## 9. 禁止项

- 大面积浅绿 / 翡翠绿 / 荧光绿成功态。
- 琥珀色保存按钮、金书签填充、橙色营销 CTA。
- 绿色「已保存」徽章、绿色保存横幅、重复的成功通知。
- 浅蓝原文条与浅蓝提示卡。
- 紫色渐变、彩色 icon 行、Emoji 结构图标。
- 跟随系统强调色导致色板失控。
- 用 WebView / HTML / CSS 替代原生 Go UI。

## 10. 验证

- 正文与辅助文字 ≥ 4.5:1；图标与大字号 ≥ 3:1。
- 浅色与深色都要实机截图检查：词卡、长难句卡、写作卡、设置页、悬浮条。
- `gofmt`、`go vet ./...`、`go build ./...`、`go test ./...` 全部通过。
- 原生控件树用 `mygo-automation snapshot -i` 检查，视觉用 `screenshot` 检查；`impeccable detect` 不覆盖 Go 原生 UI，不能替代截图。
